# Tienda de Camisetas · WhatsApp + AI Agent

Automatización de atención y ventas por WhatsApp desarrollada con n8n, PostgreSQL e inteligencia artificial.

## Funcionalidades

- Atención automática de clientes por WhatsApp
- Búsqueda de camisetas y disponibilidad en tiempo real
- Consulta de stock por variante y talla
- Preparación de pedidos mediante borradores
- Confirmación de pedidos mediante botones de WhatsApp
- Gestión de inventario
- Consulta del estado de pedidos
- Memoria de conversaciones
- Derivación a un asesor humano
- Manejo de errores técnicos
- Integración con Meta WhatsApp Cloud API
- PostgreSQL como base de datos

## Arquitectura

WhatsApp → Meta Cloud API → n8n → AI Agent → PostgreSQL

## Tecnologías

- n8n
- PostgreSQL
- WhatsApp Cloud API
- OpenAI / Anthropic
- JavaScript
- Docker
